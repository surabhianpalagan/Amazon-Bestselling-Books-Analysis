
# Amazon Bestselling Books Analytics Dashboard

## Project Overview
An interactive data analytics dashboard built using
Python, Pandas, Streamlit, and Plotly.

The project analyzes Amazon bestselling books from
2009 to 2019 to explore trends in book ratings,
prices, authors, genres, and customer reviews.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit

## Features
- Interactive dashboard
- Genre and year filters
- Top 10 bestselling authors
- Highest-rated books
- Book pricing trends
- Customer review analysis
- Downloadable filtered CSV data

## How to Run

1. Download the project.
2. Install dependencies:

   pip install -r requirements.txt

3. Download the Amazon bestselling books dataset
   from Kaggle and save it as bestsellers.csv.

4. Start the dashboard:

   streamlit run dashboard.py

## Dataset
Amazon Top 50 Bestselling Books 2009–2019

Source:
https://www.kaggle.com/datasets/sootersaalu/amazon-top-50-bestselling-books-2009-2019
